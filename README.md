# StudySprint

A zero-dollar MVP inspired by the app-building workflow in the reference video.

## Stack
- Plain HTML/CSS/JavaScript
- LocalStorage for data
- PWA install support
- GitHub for source control
- Netlify for hosting

No paid AI API, database, subscription platform, or app-store developer account is required for this MVP.

## Features
- Add and complete study tasks
- Focus timer
- Daily streak
- Progress dashboard
- Offline cache
- Installable on Android as a PWA

## Next monetization step
Keep the core planner free. Add optional premium features only after users are actually using the product.
